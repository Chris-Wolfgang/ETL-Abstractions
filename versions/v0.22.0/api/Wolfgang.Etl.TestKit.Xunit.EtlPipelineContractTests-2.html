Remarks

Inherit from this class to verify that your source composes with a loader sink into an EtlPipeline that runs end-to-end and delivers every item, and that its EtlPipelineProgress counts the records pulled from the source (ExtractedItemCount) and delivered to the sink (LoadedItemCount).

Implement CreateSourceItems() (the data the source streams), CreateSink() (the loader), and GetLoadedItems() (read what the harness-composed Sink received, or null if the loader does not expose it). The Sink property — rather than a parameter — carries the composed loader so the override needs no null-argument validation.
