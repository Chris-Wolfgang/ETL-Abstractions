Class ItemErrorContext

Namespace
Wolfgang.Etl.Abstractions

Describes a single item that failed to process. It is passed to a stage's OnItemError policy so the policy can record the failure (a "dead letter") and decide whether to Skip the item or Abort the run.

rawContent Func<string>

An optional, lazily-evaluated accessor for the item's raw source text (a line, a fixed-width record, an XML element). It is a delegate rather than a value so a stage that would have to buffer or reconstruct the raw content pays that cost only if the policy actually reads it.
