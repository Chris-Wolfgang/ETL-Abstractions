A convenience LoaderBase<TDestination, TProgress> that reports progress with the built-in Report type and supplies a default CreateProgressReport(), so a derived loader only has to implement LoadWorkerAsync. Use this instead of the two-type-parameter base when you don't need a custom progress-report type — it removes the progress-record and CreateProgressReport boilerplate. Override CreateProgressReport() if you want to enrich the report (for example set a known total).

public abstract class LoaderBase<TDestination> : LoaderBase<TDestination, Report>, ILoadWithProgressAndCancellationAsync<TDestination, Report>, ILoadWithProgressAsync<TDestination, Report>, ILoadWithCancellationAsync<TDestination>, ILoadAsync<TDestination>, IReportsItemErrors, IAsyncDisposable, IDisposable where TDestination : notnull
