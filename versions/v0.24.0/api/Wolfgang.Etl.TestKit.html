Wolfgang.Etl.Abstractions

Namespace Wolfgang.Etl.TestKit

Classes

DelayingExtractor<T>

An extractor double that waits a configurable delay before yielding each item, simulating a latent / backpressured source. Useful for exercising timeout, cancellation-promptness, and progress-cadence behaviour that an instantaneous in-memory source cannot.

FaultyExtractor<T>

An in-memory extractor for testing error-handling paths. It yields items from an IEnumerable<T> like a normal extractor, but can be configured to inject deterministic faults — throwing at a given item, throwing after completion, or duplicating an item — so consumers can exercise mid-stream failure, finalization failure, and de-duplication logic without hand-rolling broken fakes.

FaultyLoader<T>

An in-memory loader for testing error-handling paths. It consumes the source stream like a normal loader, but can be configured to inject deterministic faults — throwing at a given item, throwing after completion, or duplicating an item — so consumers can exercise mid-stream failure, finalization failure, and idempotency logic without hand-rolling broken fakes.

FaultyTransformer<T>

A pass-through transformer for testing error-handling paths. It returns each item unchanged like a normal transformer, but can be configured to inject deterministic faults — throwing at a given item, throwing after completion, or duplicating an item — so consumers can exercise mid-stream failure, finalization failure, and de-duplication logic without hand-rolling broken fakes.

ManualProgressTimerCore

A manually-driven progress timer for tests: instead of a real Timer firing on an interval, the stage's progress callback fires only when Tick() is called, making progress-callback assertions deterministic. Attach it to a stage with WithManualProgressTimer<TSource, TProgress>(ExtractorBase<TSource, TProgress>, ManualProgressTimerCore) (and the loader / transformer overloads).

ManualTimeSource

A controllable time source for tests: time stands still until Advance(TimeSpan) is called, making a stage's Report timing metrics — Elapsed, ItemsPerSecond, PercentComplete, and EstimatedRemaining — deterministic rather than wall-clock-dependent.

ProgressTimerExtensions

Extension methods that attach a ManualProgressTimerCore to a stage so its progress callback fires deterministically (on Tick()) instead of on a real timer interval.

RecordingMiddleware<T>

A test IItemMiddleware<T> that records every item passed through it and, by default, keeps each item flowing. Supply a policy to transform or drop items, and inspect Observed to assert exactly what the middleware saw, in order.

RetryingExtractor<T>

An extractor double that throws a transient fault on its first failFirstAttempts worker invocations and then succeeds, driven through a retry override of the Wolfgang.Etl.Abstractions 0.20 WrapWorkerExecution resilience seam. It both demonstrates how to build stream-level retry on a stage and serves as the reference component exercised by RetryContractTests (in Wolfgang.Etl.TestKit.Xunit).

SnapshotTestLoader<T>

An in-memory loader that captures every item it receives and renders them as a single, deterministic, diff-friendly Snapshot string — ready to hand to an approval / snapshot-testing framework such as Verify.

TestExtractor<T>

An in-memory extractor for use in tests, examples, and benchmarks. Yields items from an IEnumerable<T>, an IEnumerator<T>, or a factory delegate, depending on which constructor is used.

TestLoader<T>

A simple in-memory loader for use in tests, examples, and benchmarks. Iterates all items from the source stream and, when constructed with collectItems: true, makes them available via GetCollectedItems() after the load completes.

TestTransformer<T>

A pass-through transformer for use in tests, examples, and benchmarks. Returns each item unchanged, with no transformation applied.

TimeSourceExtensions

Extension methods that attach a ManualTimeSource to a stage so its Report timing metrics can be driven deterministically in tests.
