Wolfgang.Etl.Abstractions

Namespace Wolfgang.Etl.TestKit.Xunit

Classes

AllocationBudgetContractTests<TSut>

Opt-in xUnit contract-test base asserting that a repeatable operation's hot path stays within a declared per-item allocation budget — so a downstream author can lock in that their own extractor / loader / transformer keeps an allocation-free (or below-a-declared-N) hot path.

CancellationContractTests<TSut>

Abstract base class providing xUnit contract tests that verify a stage honours cancellation promptly — it stops shortly after the token is cancelled rather than draining its source, throws OperationCanceledException, and processes nothing when handed an already-cancelled token.

CancellationOutcome

The result a derived CancellationContractTests<TSut> reports back to the base after driving its stage under cancellation.

DisposableStageContractTests<TSut>

Abstract base class providing xUnit contract tests for the disposability guarantees the ETL base classes gained in Wolfgang.Etl.Abstractions 0.14.0 (IDisposable / IAsyncDisposable) and 0.17.0 (using a disposed stage throws ObjectDisposedException).

ErrorHandlingContractTests<TSut>

Abstract base class providing xUnit contract tests for a stage that opts into the per-item error hook introduced in Wolfgang.Etl.Abstractions 0.18.0 (OnItemError / HandleItemError / CurrentErrorItemCount, ItemErrorAction, ItemErrorContext).

ErrorHandlingOutcome

The observable outcome of running a stage over a scenario containing exactly one failing item, used by ErrorHandlingContractTests<TSut>.

EtlPipelineContractTests<TItem, TProgress>

Abstract base class providing xUnit contract tests for composing a source and a sink into the Wolfgang.Etl.Abstractions 0.16 EtlPipeline (EtlPipeline.Create().From(...).To(...).RunAsync()) and for the EtlPipelineProgress it reports.

EtlScenario

Entry point for building a fluent end-to-end ETL scenario over the Wolfgang.Etl.TestKit doubles and asserting its final state in a single expression. See EtlScenario<T>.

EtlScenario<T>

A fluent builder that composes an extract → (transform) → load pipeline from the Wolfgang.Etl.TestKit doubles — optionally injecting a fault into the extractor or loader — runs it through the Wolfgang.Etl.Abstractions EtlPipeline, and asserts the final state (loaded items, aggregate error count, or a terminal exception) in one call.

ManualProgressTimer

A controllable implementation of IProgressTimer for use in unit tests. Fires Elapsed synchronously on demand via Fire(), rather than on a background thread-pool thread after a real time interval.

ProgressAssert

Provides xUnit-style assertions for validating sequences of progress reports captured by a ProgressCapture<T>.

ProgressCapture<T>

An IProgress<T> implementation that captures every reported value, synchronously, on the calling thread.

RetryContractTests<TSut>

Abstract base class providing xUnit contract tests for a stage whose Wolfgang.Etl.Abstractions 0.20 WrapWorkerExecution override adds a retry / resilience strategy: a transient fault that clears within the retry budget completes the run, and a fault that never clears fails after the maximum number of attempts (no infinite loop).

RetryOutcome

The result a derived RetryContractTests<TSut> reports back to the base after driving its stage under a fault with a retry policy.
