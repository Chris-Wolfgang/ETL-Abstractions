Abstract base class providing xUnit contract tests for any type that implements ILoadWithCancellationAsync<TDestination>.

public abstract class LoadWithCancellationAsyncContractTests<TSut, TItem> where TSut : ILoadWithCancellationAsync<TItem> where TItem : notnull

Type Parameters

TSut

The type under test. Must implement ILoadWithCancellationAsync<TDestination>.

TItem

The type of item the loader consumes.

Examples

public class MyLoaderCancellationContractTests
    : LoadWithCancellationAsyncContractTests<MyLoader, MyRecord>
{
    protected override MyLoader CreateSut(int itemCount) =>
        new MyLoader(connectionString);

    protected override IReadOnlyList<MyRecord> CreateSourceItems() =>
        new List<MyRecord> { new("a"), new("b"), new("c") };
}

Remarks

The source items sequence must contain at least three items so that cancellation mid-sequence can be meaningfully tested.
