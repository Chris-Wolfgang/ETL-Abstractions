An extractor double that waits a configurable delay before yielding each item, simulating a latent / backpressured source. Useful for exercising timeout, cancellation-promptness, and progress-cadence behaviour that an instantaneous in-memory source cannot.

Examples

// Each item arrives 20 ms apart:
var extractor = new DelayingExtractor<int>(Enumerable.Range(0, 100), TimeSpan.FromMilliseconds(20));
using var cts = new CancellationTokenSource(TimeSpan.FromMilliseconds(50));
// Enumerating with cts.Token throws OperationCanceledException after ~2-3 items.

Remarks

The delay is awaited with Delay(TimeSpan, CancellationToken) before each item is yielded, so a cancelled token interrupts the wait and the extractor stops promptly (throwing OperationCanceledException) rather than draining the source. Pair it with CancellationContractTests (in Wolfgang.Etl.TestKit.Xunit) to verify a stage cancels quickly and leaves its counters consistent.

Supply a single TimeSpan for a uniform delay, or a Func<int, TimeSpan> to vary the delay by zero-based item index. LoaderBase<TDestination, TProgress>-style SkipItemCount / MaximumItemCount bounds are honoured.
