Remarks

Per ADR-0009, stage configuration is supplied as a record passed to the constructor rather than assigned to properties after construction, so that it is settled before a run rather than mutated during one.

A derived extractor inherits this record to add its own settings — for example a CsvExtractorOptions : ExtractorOptions adding a Delimiter — so that a caller configures the whole stage, base members included, through a single object. 

var options = new ExtractorOptions
{
    MaximumItemCount = 100,
    SkipItemCount    = 10
};

WorkerResilience is deliberately absent. Its type differs on every base stage (it is generic over the stage's own type parameter), so including it here would force every derived options record in the fleet to become generic for the sake of one delegate. It is a resilience strategy rather than a setting — the same category as ILogger — and remains an init-only property on the stage.
