Resolves a property-selector lambda such as x => x.Name to the PropertyInfo it selects. The shared primitive behind the per-library code-first schema builders, so every ETL library validates selectors the same way.

public static PropertyInfo Resolve<T, TProperty>(Expression<Func<T, TProperty>> selector)

Parameters

selector Expression<Func<T, TProperty>>

A lambda whose body is a single property access on its parameter, such as x => x.Name. Inherited properties are accepted.

Returns

PropertyInfo

The PropertyInfo for the selected property.

Type Parameters

T

The type that declares (or inherits) the property.

TProperty

The selector's result type. May be object for a value-type property; the boxing conversion the compiler inserts is unwrapped.

Exceptions

ArgumentNullException

selector is null.

ArgumentException

selector selects a field, calls a method, chains member access (x => x.Address.City), returns the parameter itself, or computes a value instead of reading a property of its parameter.
