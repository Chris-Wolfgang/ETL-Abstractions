Abstract base class providing opt-in xUnit idempotency contract tests for a transformer derived from TransformerBase<TSource, TDestination, TProgress>, whatever its progress type.

Examples

public class MyTransformerIdempotencyTests
    : IdempotentTransformerContractTests<MyTransformer, MyRecord, MyProgress>
{
    protected override MyTransformer CreateSut(int itemCount) => new MyTransformer();

    protected override IReadOnlyList<MyRecord> CreateExpectedItems() =>
        new List<MyRecord> { new("a"), new("b"), new("c"), new("d"), new("e") };
}

Remarks

This base class is opt-in. Inherit from it only if your transformer supports being run more than once on the same instance and produces the same result each time.

It runs the same tests as the two-parameter base and reads CurrentItemCount from the transformer directly, so a transformer with its own progress type needs no override.
