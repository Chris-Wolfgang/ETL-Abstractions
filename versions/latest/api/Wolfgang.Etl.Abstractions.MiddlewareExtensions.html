WithMiddleware<T>(IAsyncEnumerable<T>, IEnumerable<IItemMiddleware<T>>, CancellationToken)

Pipes every item of source through middlewares in order: each middleware sees the item the previous one passed on. If any middleware drops the item (Drop<T>()), the remaining middleware is not run and the item is removed from the stream.
