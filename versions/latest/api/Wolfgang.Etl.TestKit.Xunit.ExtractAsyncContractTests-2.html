Remarks

Inherit from this class and implement the abstract factory methods to verify that your extractor correctly satisfies the IExtractAsync<TSource> contract.

At minimum you must provide a SUT instance and a non-empty expected item sequence containing at least three items. The same expected sequence must be returned on every call to CreateExpectedItems() within a single test run.
