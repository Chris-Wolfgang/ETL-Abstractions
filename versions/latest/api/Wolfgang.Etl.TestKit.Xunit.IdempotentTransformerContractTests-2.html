public class MyTransformerIdempotencyTests
    : IdempotentTransformerContractTests<MyTransformer, MyRecord>
{

        new MyTransformer();

    protected override IReadOnlyList<MyRecord> CreateExpectedItems() =>
        new List<MyRecord> { new("a"), new("b"), new("c"), new("d"), new("e") };
}

Remarks

This base class is opt-in. Inherit from it only if your transformer supports being run more than once on the same instance and produces the same output for the same input each time, with no accumulated side effects. Single-use components — for example a transformer that maintains running state intended to span a single pipeline — must not inherit this class.

Each test calls CreateSut(int) exactly once and then transforms the same input twice, asserting that the second run is unaffected by the first.

Remarks

The default implementation reads CurrentItemCount assuming the transformer derives from TransformerBase<TSource, TDestination, TProgress> with a Report progress type, which is the convention for ETL transformers. Override this when the transformer exposes its progress count through a different progress type or member.

TransformAsync_when_called_twice_CurrentItemCount_resets_Async()

Verifies that CurrentItemCount reflects only the most recent run: after transforming the same input twice on the same instance, the count equals the number of items produced by the second run alone, not the cumulative total across both runs.
