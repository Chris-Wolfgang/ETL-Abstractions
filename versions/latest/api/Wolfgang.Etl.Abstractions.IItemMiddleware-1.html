A composable, reusable hook for cross-cutting per-item behaviour (logging, validation, metrics, throttling, deduplication) that can be attached to any stream without modifying the extractor, transformer, or loader that produced it. Attach one or more with WithMiddleware<T>(IAsyncEnumerable<T>, IItemMiddleware<T>, CancellationToken); they run in the order attached, each seeing the item the previous one passed on.
