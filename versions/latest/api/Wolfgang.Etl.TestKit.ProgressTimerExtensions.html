Remarks

These reach the internal timer-core seam on the base classes via the friend relationship between Wolfgang.Etl.TestKit and Wolfgang.Etl.Abstractions, so a component needs no per-type timer-injection plumbing. Attach the timer before the run starts; the stage builds its progress timer when the run begins.
