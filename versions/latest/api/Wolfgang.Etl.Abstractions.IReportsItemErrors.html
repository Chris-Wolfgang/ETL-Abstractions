Implemented by an ETL stage that counts items its error policy discarded, so a pipeline can read that count uniformly regardless of the stage's concrete type. ExtractorBase<TSource, TProgress>, LoaderBase<TDestination, TProgress>, and TransformerBase<TSource, TDestination, TProgress> all implement it, and EtlPipeline sums CurrentErrorItemCount across every stage that reports it into ErrorItemCount.
