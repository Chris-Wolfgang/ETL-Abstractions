Remarks

Per ADR-0009, stage configuration is supplied as a record passed to the constructor rather than assigned to properties after construction, so that it is settled before a run rather than mutated during one. Derived loaders inherit this record to add their own settings, giving a caller a single object to configure the whole stage.

WorkerResilience is deliberately absent — see the corresponding note on ExtractorOptions.
